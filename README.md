# GDM cfRNA and Placental Single-Cell Transcriptomic Analysis

## Overview

This repository provides nine R scripts for selected core analyses of longitudinal plasma cell-free RNA (cfRNA) and placental single-cell transcriptomic data in gestational diabetes mellitus (GDM). The plasma and placental analyses use separate datasets.

## Analysis scripts

| Script | Main purpose |
| --- | --- |
| `01_cohort_selection.R` | cfRNA sample selection, covariate balancing, and expression-matrix matching |
| `02_cfRNA_DESeq2.R` | Differential expression analysis across three gestational stages |
| `03_cfRNA_GSEA.R` | Gene set enrichment analysis of cfRNA differential expression results |
| `04_cfRNA_ssGSEA.R` | Single-sample pathway scoring and stage-specific effect estimation |
| `05_clustering_16_modules.R` | Functional module identification and module scoring |
| `06_cell_origin_analysis.R` | Module–cell-type signal associations and permutation testing |
| `07_clinical_associations.R` | Associations between functional modules and clinical indicators |
| `08_placenta_pseudobulk_DESeq2.R` | Cell-type-specific placental pseudobulk differential expression analysis |
| `09_placenta_GSEA.R` | Placental gene set enrichment analysis |

Scripts **01–07** cover plasma cfRNA analyses. Scripts **08–09** form a separate placental single-cell analysis branch; Script 09 uses results from Script 08.

## Requirements

The analyses use **R** and packages including `DESeq2`, `tidyverse`, `GSVA`, `msigdbr`, `clusterProfiler`, `dynamicTreeCut`, `GOSemSim`, `Seurat`, `Matrix`, `data.table`, and `nlme`. See the individual scripts for additional dependencies and parameter settings.

## Inputs and usage

Run the scripts from the repository root using the project-relative paths defined in each script. For example:

```bash
Rscript scripts/01_cohort_selection.R
```

Input data and intermediate results must be provided separately. In particular:

- Script 04 requires a curated table of significant GO-BP GSEA pathways, which is not automatically generated by Script 03.
- Script 06 uses the included `config/deconformer_celltypes_63.csv` file and requires cell-type-associated scores in the matched sample metadata.
- Script 07 requires clinical data and a verified, private age-correction file.
- Script 08 requires a placental Seurat object with raw counts and the expected sample metadata.

## Data availability

Raw sequencing data, participant-level clinical data, and controlled intermediate files are not included in this repository. Please refer to the associated manuscript's Data Availability statement for data access information.

This repository contains **selected core analysis scripts**, not a complete end-to-end reproduction of every analysis or figure in the manuscript.
